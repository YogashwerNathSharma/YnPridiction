# Statistical methodology and responsible presentation

## What trend analysis can show
Historical data can describe frequencies, streaks, rolling distributions, and transitions. These are descriptive statistics.

## What it cannot establish
For a fair independent random draw, earlier outcomes do not change the probability of the next outcome. A hot number is not necessarily more likely next, and a cold number is not due.

## Required evaluation
1. Sort observations chronologically.
2. Reserve the latest segment as a holdout set.
3. Compare any model with a simple uniform or empirical baseline.
4. Report sample size, accuracy, log loss/Brier score where applicable, and confidence intervals.
5. Avoid showing a single percentage as a guaranteed confidence score.

## Product rule
Use labels such as “historical frequency ranking” and “descriptive signal”. Avoid “sure shot”, “fixed”, “guaranteed”, or “best winning prediction”.
